
# VirusMonitor

VirusMonitor is een epidemiologisch analyseplatform
dat historische gegevens gebruikt om de verspreiding
van infectieziekten in Nederland te onderzoeken.

## Doel van het project

Het doel is om met behulp van data-analyse,
wiskundige modellen en machine learning patronen
in virusverspreiding te herkennen en voorspellingen
te visualiseren.
